## Goal

A walk through all 13 workspaces at 1440 and 390 px found that the token
layer (v167 Arctic Navy, v168 motion, v179) is sound, but the app reads as
less professional than it is. The causes sit in four shared primitives, not
in the pages. Panel titles speak in three voices: mono caps on `sb-panel`, bold
sans on `sb-panel-header`, spaced caps on stat tiles. Titles also look like
field labels, so the hierarchy is flat. Stat tiles draw a framed box inside a
framed panel. Display figures are set in a code face that reads wide and
blocky at 28 px. Secondary text uses `--text-faint`, a colour the token file
itself reserves for rules and dividers (~2:1 contrast). And the loading
skeleton is the loudest thing on the Dashboard while it loads.

Once shipped:

- Every panel title is one sentence-case Inter 600 line at 14 px, with its meta
  (`N=`, `all-time`, totals) beside it. Field and tile labels keep the mono
  caps `.sb-label`.
- The header rule shows only where it separates something: on flush panels,
  and on panels whose body opens with a tab strip or a table (`divided`).
- The three stat-tile rows inside panels (Dashboard performance, Risk metrics,
  Calendar summary) become `sb-stat-strip`s: tiles split by hairlines, with no
  nested frames. Each site keeps its column counts.
- Display figures share one face: Inter 600 with tabular digits and slight
  negative tracking.
- Tile labels, `N=` and hints become readable (`--text-muted`).
- The skeleton draws thin, shaped bars that pulse gently instead of
  full-height slabs with a sweeping shimmer.

How it works:

- Three tier-2 tokens: `--font-figure`, `--figure-weight`, `--figure-tracking`.
- Each display-figure rule is rewritten in its own component, because a global
  class loses to a component's scoped selector.
- The strip draws no rules itself. It sets inherited custom properties
  (`--figure-rule`, `--tile-bg`, `--tile-border`, `--tile-radius`,
  `--tile-tint-off`, `--panel-shadow-lift`) that the tiles already read, or
  learn to read, on their own hosts. This is the mechanism `sb-figure-strip`
  uses today, so nothing needs `::ng-deep`.
- A tile outside a strip looks exactly as it does today.

Left alone:

- colour values: `palette.css` and `chart_style.THEME` are untouched;
- data, API and copy;
- the panel surface: gradient, border, radius and shadow;
- table cells and every other mono column;
- page-level tile rows: Analytics overview and partials, the Calendar day
  drawer, `calendar-day.ts`;
- the shell, toolbars and per-workspace layout, which are later specs;
- the other ~100 `--text-faint` uses outside the files named here.

Success means:

- every spec Testing bullet has a passing unit test;
- the gate specs (`primitives.spec.ts` G3 and radius, `tokens.spec.ts`,
  `workspace-consistency.spec.ts`, `elevation.spec.ts`,
  `vertical-centre.spec.ts`) pass unchanged;
- `motion-css.spec.ts` and `async.spec.ts` change only where the spec says;
- a three-width visual pass (1440 / 1024 / 390) of Dashboard, Analytics, Risk
  and Calendar shows no horizontal page scroll and the pinned column counts;
- one full suite is green (`0 failed`, `0 xfailed`).

## Architecture

- **Tokens** (`frontend/src/styles/tokens.css`, tier 2 beside `--font-num`): `--font-figure: var(--font-sans)`, `--figure-weight: 600`, `--figure-tracking: -0.02em`. `tests/charts/resolved_tokens.json` is regenerated by `python scripts/dev/dump_tokens.py` in the same commit.
- **`sb-panel`** (`ui/layout.ts`): `h2` loses `sb-label` and gains the title declarations; new `divided = input(false)`; `<header [class.ruled]="flush() || divided()">` with a transparent bottom border unless `.ruled`; `.body` gains `[class.tight]="!!heading() && !flush() && !divided()"` (`padding-top: var(--space-4)`); `.panel-toggle` → `--text-muted`. The six non-flush headed panels whose body opens with a tab strip or a table get `[divided]="true"`, pinned by a source scan.
- **`sb-panel-header`** (`ui/panel-header.ts`): `h2` = the same title; `.n, .all-time` → `--font-num` / `--text-muted` (`all-time` keeps `--warn`); `.total` → figure face at `--text-chip` (V186-5).
- **Tiles** (`ui/stat-tile.ts`, `ui/metric-card.ts`): `:host` reads `--figure-rule` start-edge borders with `box-sizing: border-box`; surface reads `--tile-bg` / `--tile-border` / `--tile-radius`; metric-card tint reads `--tile-tint-off`; labels use `.sb-label`; faint text → muted.
- **`sb-stat-strip`** (new `ui/stat-strip.ts`): `:host` sets the custom properties and `overflow: hidden`; projects children into `div.sb-strip-grid` (`margin: -1px 0 0 -1px`), adding `.sb-strip-fixed` when `cols` is set. Global `.sb-strip-grid` / `.sb-strip-fixed` column rules live in `frontend/src/styles.css` (not scanned by workspace-consistency); the lift translate is cancelled by one `motion.css` rule.
- **Figure face** (V186-5): five scoped rules rewritten to `font-family: var(--font-figure); font-weight: var(--figure-weight); letter-spacing: var(--figure-tracking); font-variant-numeric: tabular-nums;` and `num` dropped from those templates.
- **Skeleton** (`ui/async.ts`): cells keep their `--control-h` box, draw an 8 px `::before` bar of width `--bar-w` (column-index sequence); new `'tiles'` branch on `.sb-strip-grid`; keyframe `sb-skeleton-pulse` replaces `sb-shimmer`; Reduced / Off rules retargeted.

**Tech stack:** Angular (zoneless, signals, emulated encapsulation), Vitest 4 via `@angular/build:unit-test` (jsdom), CSS custom properties; Python only for the token fixture; Playwright (`frontend/scripts/browse.mjs`) for the visual check.

## Global Constraints

- Presentation only: no colour value, data, API or copy changes. `palette.css` and `chart_style.THEME` untouched.
- Panel title (both primitives): `font-family: var(--font-sans); font-weight: 600; font-size: var(--text-body); color: var(--text); letter-spacing: normal;` and no `text-transform` declaration. Text passed as a heading is never rewritten (no ALL-CAPS literals exist; brief §5).
- `.sb-label` in `frontend/src/styles.css` is unchanged and stays the field/tile label style.
- `--panel-bg`, `--panel-border`, `--panel-radius`, `--panel-shadow` unchanged. The `sb-panel` `header` rule keeps the literal `min-height: calc(var(--control-h) + 2 * var(--space-10) + 1px);` and gains `border-bottom: 1px solid transparent;`; `header.ruled` makes it `var(--border)`.
- Strip columns: default `repeat(auto-fit, minmax(min(100%, 140px), 1fr))`; with `cols`: `--strip-cols` from 1024 px, `--strip-cols-md` (default 2) 640–1023 px, 2 below 640 px. Dashboard `cols=4 colsMd=2`, Risk no `cols`, Calendar `cols=4 colsMd=4`.
- Figure tokens: `--font-figure: var(--font-sans);`, `--figure-weight: 600;`, `--figure-tracking: -0.02em;` — tier 2, no `var(--x, fallback)` in tokens.css. `--font-num: var(--font-mono);` stays verbatim.
- Component-scoped properties (`--figure-rule`, `--tile-bg`, `--tile-border`, `--tile-radius`, `--tile-tint-off`, `--strip-cols`, `--strip-cols-md`, `--bar-w`) never go into tokens.css or the fixture.
- No `::ng-deep` into tiles or the strip; no new non-inset `box-shadow:` anywhere (`primitives.spec.ts` G3: motion.css casts exactly `var(--panel-shadow-lift)` and `var(--glow-accent)`); every `border-radius` reads a radius token, `0`, `50%` or `inherit` (a `var(--tile-radius, var(--panel-radius))` value carries no px and passes).
- Skeleton: bar widths by column index `40%, 65%, 30%, 55%` repeating; bar height 8 px, `--radius-sm`; `'tiles'` cell = label bar 35% above value bar 60%; `sb-skeleton-pulse` = opacity 0.5 → 0.9 → 0.5, `calc(1800ms * var(--motion-scale))`, ease-in-out, infinite. `emptyReason` and the single `aria-live` region are untouched (known-traps.md).
- Thin-sample tiles keep both cues: value opacity 0.62 and the "· thin sample" words.
- Per-task verification is the narrow run: frontend `cd frontend && npx ng test --watch=false --include <spec path relative to frontend/>`; Python `python scripts/dev/testrun.py file tests/dev/test_dump_tokens.py`. A Vitest "Timeout waiting for worker to respond" at 60 s is load: re-run the same file (`docs/claude/testing-cost.md` § Frontend). One full suite only, in V186-12.
- Every task ships its own unit tests; every TS function stays well under complexity 15 (the Python gate does not cover TS, keep the same bar).
- Every UI change is checked at three widths (`docs/claude/ui-design.md`); V186-11 does the pass.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. One scoped commit per task, in the worktree; never commit on `main` until V186-12's merge.
