**Goal:** Split the admin's design tokens into three tiers (palette -> semantic -> component), swap the palette to Arctic Navy, move geometry to the refined terminal (8/6/999/2px radii, two-level elevation, gradient panels and buttons), keep the Discord chart PNGs in lockstep with a style-versioned chart cache, and gate all of it.

**Architecture:** `frontend/src/styles/palette.css` (new, tier 1) is the only file holding hued literals; `tokens.css` tier 2 becomes `var(--<palette-name>)` references and gains a tier-3 `:root` block at its end; `styles.css` imports palette before tokens and carries the global `.sb-panel` and `.elev-overlay` shadow classes. One token resolver per language (`scripts/dev/dump_tokens.py` in Python, `frontend/src/app/ui/testing/resolve-token.ts` in TypeScript) follows `var()` hops to literals; both must reproduce the committed fixture `tests/charts/resolved_tokens.json`, which also feeds a flattened `:root` into the jsdom test document so no spec ever sees a nested `var()`. `swingbot/core/charts/chart_style.py:THEME` mirrors the resolved values byte for byte and exports `STYLE_VERSION`, folded into every chart-cache key in `cache.py:_key_hash`.

**Tech Stack:** Angular ~21.2 (standalone, zoneless, OnPush), vitest via `ng test` (`@angular/build:unit-test`, jsdom); Python 3.11, matplotlib/mplfinance, pytest via `scripts/dev/testrun.py`; Playwright via `frontend/scripts/browse.mjs` for the visual pass.
