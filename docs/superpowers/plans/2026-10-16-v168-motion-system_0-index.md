**Spec:** [`docs/superpowers/specs/2026-10-16-v168-motion-system-design.md`](../specs/2026-10-16-v168-motion-system-design.md) (sections 1-6, Out of scope, Testing; **`## Amendments from the plan brief` binds the plan and overrides earlier sections where they differ**; every applied `## Panel review` finding is a requirement)
**Bump:** ui minor; bot none
**Edge:** none (integrity)
**Screen:** exempt (integrity)

**Goal:** Give the admin a single motion home (`frontend/src/styles/motion.css`), a persisted shell Motion preference (On / Reduced / Off, default On, the OS reduced-motion setting deliberately ignored), and the ten animations of spec §3 wired into the shell and the shared `ui/` primitives, without ever replaying an entrance on a push or a refetch.

**Architecture:** `tokens.css` gains `--motion-scale` and three new durations inside v167's tier-3 block and loses its global reduced-motion block; `styles/motion.css` (imported after `tokens.css`) holds every `@keyframes`, every shared motion class and every `[data-motion=on|reduced|off|pending]` rule. A root `MotionService` (a signal over `PreferencesStore`'s `shell.motion`) is the only TS source of the mode; the shell writes it to `<html data-motion>`, which starts as `pending` in `index.html`. A root `RouteEntryService` keeps an activation id that moves only on a real path change, and every entrance consumer (route host, count-up, draw-in) spends a once-per-activation `claim(key)` and reports its start to a `MotionStarts` recorder that the no-replay gate reads.

**Tech Stack:** Angular ~21.2 (standalone, zoneless, OnPush; `animate.enter`/`animate.leave` from `@angular/core`; `@angular/animations` is not installed and stays so), vitest via `ng test` (`@angular/build:unit-test`, jsdom), Python 3.11 `scripts/dev/dump_tokens.py` for the token fixture, Playwright via `frontend/scripts/browse.mjs` for evidence.

## Review Focus

1. **Replay safety (MO7, MO8, MO15, MO17):** the activation id moves only on a path change; background refresh, same-URL reload and query-only changes do not move it; a recreated `sb-async` child cannot animate twice. The gate drives a real `navigateByUrl` with `BACKGROUND_REFRESH_INFO`.
2. **Off keeps every fallback (MO6):** each of the nine sites has its `[data-motion=off]` rule; spinners keep turning.
3. **`pending` suppresses the cold-load burst (MO4, MO5):** `<html data-motion="pending">` from `index.html` until preferences load; the OS setting is never read.
4. **Exit animations never strand a dialog (MO12):** the `closing` path always ends in `dialog.close()` via `animationend` or the fallback timer; under Off/pending close is immediate; Escape and backdrop go the same way.
5. **The token fixture stays in lockstep (MO2, MO6)**, and the G3 / colour gates are extended only where the ledger says.
