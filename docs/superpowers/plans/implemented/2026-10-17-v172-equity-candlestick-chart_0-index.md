**Goal:** Replace the Dashboard's 30-point equity sparkline with a candlestick chart (1H · 4H · 1D · 1W, mark-to-market or closed-trades-only, OHLC readout), fed by raw equity samples the trade monitor records into a new `equity_samples` table plus a one-off daily backfill from raw bars.

**Architecture:** One equity definition in `swingbot/core/tracking/equity.py` (realized legs walk, unrealized per open position, ledger and PENDING filters) is shared by the live recorder (`trade_monitor`, every 5 min during regular hours), the backfill script and the admin API. Raw samples live in Postgres (`equity_samples`, Alembic `v172_001`); a pure bucketing module (`swingbot/core/tracking/equity_candles.py`) builds candles on request in `GET /api/v1/equity/candles`. The SPA gets a `sb-equity-candles` component (lightweight-charts candlestick series) backed by an `EquityCandlesStore` that refetches on `scan` events and keeps timeframe/basis in server-backed preferences.

**Tech Stack:** Python 3.11, SQLAlchemy Core + Alembic (Postgres), Flask blueprint `api_v1`, discord.py tasks loop, pandas + yfinance (backfill only), Angular (signals, `@ngrx/signals` signalStore, zoneless), `lightweight-charts` v5, Vitest via `ng test`.

## Global Constraints

- **One equity definition.** Every writer and reader of equity (recorder, backfill, API realized basis, `--recompute-realized`) goes through `swingbot/core/tracking/equity.py`. Nothing in `swingbot/core` or `swingbot/commands` imports `swingbot.admin`; the admin re-imports the moved helpers.
- **Ledger:** the main book only — `split_by_ledger(trades)[0]` (`swingbot/core/tracking/ledger.py:32`) — for opens and closes alike. Weak and outlook trades never enter a sample or a candle.
- **Realized balance at `t`** = `load_account_config().get("base_balance", 0.0)` + Σ realized legs with `closed_at <= t`, legs from `expand_realized_legs` (`performance.py:484`) over every main-book trade (open PARTIAL trades included, so a banked TP1 leg is realized at its own time). A leg whose `realized_pnl_amount` or `closed_at` is `None` is skipped (as `equity_curve` does).
- **Open positions** = main-book trades with `status == "open"`, filtered like `_live_positions` (`api_v1/dashboard.py:206`): no plan → kept as is; plan `ACTIVE`/`PARTIAL` → kept with `shares = open_shares(shares, plan.legs_realized)`; any other plan status (PENDING placeholder) → dropped.
- **Unrealized of one position** = `open_shares × (price − entry) × sign` (`sign = 1` for `bullish`, else `-1`), the formula of `unrealized_pnl_amount`, moved unchanged. No size, no entry or no price → left out and counted in `skipped_n`, never priced at 0.
- **Money:** computed in `Decimal` (`Decimal(str(x))` from floats); rounded to 2 dp `ROUND_HALF_UP` exactly once, in the repository write. Columns are `double precision` (`sa.Float(53)`), per `p6_001`; the API emits those floats as JSON numbers.
- **Table `equity_samples`** (Alembic revision id `v172_001`, file `v172_001_equity_samples.py`, `down_revision` = current head, `v146_001` when this plan was written: recheck with `python -m alembic heads`): `id` bigint PK, `at` timestamptz, `realized_balance`/`unrealized_pnl`/`equity` double precision, `open_n`/`skipped_n` integer, `source` text (`live`|`backfill`), `kind` text (`point`|`day_high`|`day_low`), `backfill_run` text nullable, plus `standard_columns()` (`doc` JSONB, `updated_at`). Unique constraint `equity_samples_at_source_kind_uq` on `(at, source, kind)`; index `equity_samples_source_at_idx` on `(source, at)`. One `PROMOTION_REASONS["equity_samples"]` line per promoted column; a case in `tests/db/test_unknown_field_round_trip.py::CASES`. Downgrade drops the index and the table.
- **Recorder:** runs inside `trade_monitor` after `run_manager_tick` and `_post_plan_events`, as one call to `_record_equity_sample(live_prices)`; writes only when `is_regular_session(now)` (`swingbot/core/market/session.py:48`); at most one `live`/`point` row per 5 minutes (first tick ≥ 5 min after the last written live sample); uses only the prices this tick already fetched (no market-data call of its own); re-reads trades itself; every exception is caught, logged once per process per exception type, and the sample skipped. `trade_monitor` stays below cyclomatic complexity 15.
- **Backfill bars:** **unadjusted** daily bars fetched by the script through `yfinance.download(..., auto_adjust=False, progress=False, interval="1d")`, for traded tickers only, over the days each was held; saved under the run's output directory (`data/backfill_equity_samples/<run_id>/<TICKER>.csv`), never in a shared cache. `backtest_cache.py`, `market_data/`, `training_data.load_daily` and `fetch_backtest_data.load_cached` are never read. "Cache as-of date" in the spec = the latest bar date this run fetched (`bars_asof`).
- **Backfill rows:** per NYSE session day `D` (`nyse_calendar().sessions(...)`) from the earliest main-book `opened_at` to the session before the first `live` sample (or before today when none), session open 09:30 and close 16:00 America/New_York converted to UTC: `point`@open = realized(D−1 close) + Σ unrealized at bar open (positions entered on `D` contribute 0); `day_high`@open = realized(D) + Σ favourable extremes; `day_low`@open = realized(D) + Σ adverse extremes; `point`@close = realized(D) + Σ unrealized at bar close. Clamping: entry day range = entry price .. bar close (no bar open, no pre-entry high/low); exit day = 0 at the close, extremes from bar open to exit price only; other days = bar O/H/L/C. All four rows `source="backfill"`, `backfill_run = f"{run_id}@bars-asof-{bars_asof}"`.
- **Backfill flags:** dry run by default; `--apply` writes; without `--replace` only days with no backfill rows are written; `--replace` deletes every backfill row and rewrites in one transaction; coverage gate refuses `--apply` on any missing bar (or failed/short fetch) unless `--allow-gaps`, in which case the position is left out that day and counted in `skipped_n`; `--recompute-realized` rewrites `realized_balance` and `equity` on `live` rows from the current trade log, keeping `unrealized_pnl`. The dry run prints run id, bars as-of date, days covered and each skipped position with its reason.
- **API `GET /api/v1/equity/candles`** (`@require_auth`): `tf` ∈ `1H|4H|1D|1W` (default `1D`), `basis` ∈ `mtm|realized` (default `mtm`), `limit` integer 1..500 (default 120); anything else → `ApiError("invalid", "<name> must be one of ...", 400)`. Response keys exactly `tf, basis, currency_symbol, candles, recording_since, as_of`; `currency_symbol = config.CURRENCY_SYMBOL`; `recording_since` = ISO UTC of the earliest `live` row or `null`; `as_of` = ISO UTC now. Candle keys exactly `t, o, h, l, c, change, change_pct, samples, skipped, approx`. `_equity_30d()` and `equity_30d` are untouched.
- **Bucketing:** America/New_York wall clock (`US_MARKET_TZ`). 1H = clock hours; 4H starts at 00/04/08/12/16/20 NY (3 or 5 real hours on DST days); 1D = NY calendar day; 1W starts Monday. `t` = ISO date for 1D/1W, ISO datetime with offset for 1H/4H. mtm: `o`/`c` = earliest/latest `point` row's `equity`; `h`/`l` over every row; `skipped` = max `skipped_n`; `approx` = any `backfill` row; 1H/4H mtm read `live` rows only. realized: one step per leg, `o` = balance before the bucket's first leg, `h`/`l` over the step balances (including `o`), `c` = balance after the last; bucket without a leg omitted; `approx` false; `samples` = legs; `skipped` 0. Empty buckets omitted. `change = c − prev.c` (first candle: `c − o`), `change_pct = change / prev.c × 100` rounded 2 dp (first: against its own `o`; `null` when the base is 0). `limit` keeps the most recent candles, computed after `change` so the first returned candle still compares with its true predecessor.
- **UI copy (verbatim):** timeframe chips `1H` `4H` `1D` `1W`; basis toggle `Open + closed` | `Closed trades only`; approx caption `Before <recording_since date>: rebuilt from daily bars — ranges are outer bounds`; seam label `Recording started`; empty state `No hourly samples yet — recording started <date>` (1H/4H; `No equity samples yet` when `recording_since` is null and nothing to show); account label `Paper account · before tax and costs`; readout `date/time · O · H · L · C · ±<currency> · ±% vs prev close`, then the basis name (`Open + closed` / `Closed trades only`), then `approx` on a backfilled candle and `N positions not counted` when `skipped > 0`; the `±%` tooltip: `Change from the previous candle's close, not a return on capital`.
- **UI behaviour:** 1D and `mtm` defaults; prefs through `PreferencesStore.update(...)` with keys `dashboard.equity.tf` and `dashboard.equity.basis` (never localStorage; an unreadable value falls back to the default); approx candles hollow (transparent body, `--pos`/`--neg` border, wick `--text-faint`); no animation or flashing on update; refetch on `events.changes('scan', { minIntervalMs: MARKET_DATA_MIN_INTERVAL_MS })`; heights 160px phone (< 640), 200px tablet/desktop; controls wrap on phone with ≥ 44px targets; desktop readout inline right of the controls; no horizontal page scroll at 390, 768 and 1280px.
