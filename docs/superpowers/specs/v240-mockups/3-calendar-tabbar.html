2. Phone

Labels are always shown. Press and hold any tab and its name pops up above it (left: holding Calendar). The default tabs are Dashboard, Watchlist, Trades, Calendar and More. More opens a sheet with the remaining pages and an Edit tab bar link (middle). The editor (right) moves pages between the bar and More, with up/down buttons to reorder and a live preview.
