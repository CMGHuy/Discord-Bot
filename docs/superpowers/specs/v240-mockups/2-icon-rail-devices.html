Mockup A with an icon-only rail

The rail shrinks from 80px (icon over label) to 64px, icons only. Hover or keyboard focus shows the page name in a tooltip, and a long-press does the same on touch screens. The active page gets a mint bar and a blue tint. Hover over the rail icons to try the tooltips.

1. Icons that say what the page is

Current 16px icon on the left, proposed 24px icon on the right. Trades already uses candlesticks, so it only gets redrawn bigger.

3. Tablet (640–1023px) and phone (under 640px)

Tablet keeps the same 64px icon rail, puts the tiles 2 by 2, stacks the panels and turns the positions table into cards. Phone hides the rail and uses the bottom tab bar (Dashboard, Watchlist, Trades, Risk, More), with one tap target per destination.
